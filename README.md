# Crayonbox

Tap-to-color coloring book for kids: 12 original pages, 36 crayons, undo, clear, save as PNG and print; installable, works offline, no ads, accounts or tracking.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5291. `npm run build` writes the static site to `dist/` (serve it from the site root), `npm test` runs the core tests.
